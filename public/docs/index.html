Documentação da WebAPI — Safra Control

CRM web da ATVOS para gestão de parceiros de terras, fornecedores de cana, terras e histórico de interações. Esta página documenta todos os endpoints da WebAPI implementados no backend.

O que esta página é: documentação técnica navegável da WebAPI, servida pelo próprio backend como arquivo estático em /docs/. Ela diferencia contratos JSON de rotas HTML renderizadas pelo Express. As telas renderizadas (EJS) em rotas como /login, /parceiros e /usuarios/:id/editar usam os mesmos controllers/services quando aplicável, mas não retornam JSON.

Convenções gerais

ItemDescrição
Base URLhttp://localhost:3000 (porta definida por PORT)
FormatoRequisições e respostas em application/json (exceto exportação, que retorna CSV)
Content-TypeEm métodos com corpo (POST/PUT/PATCH): Content-Type: application/json
IDsUUID no formato 8-4-4-4-12 (ex.: 0e1f…-…-…-…-…)
Erros (padrão){ "error": "mensagem" } — os módulos de Dashboard e Exportação usam a chave { "erro": "…" }

Legenda de status codes

2xx sucesso   4xx erro do cliente   5xx erro do servidor

CódigoSignificado no projeto
200OK
201Recurso criado (acompanha header Location)
400Payload malformado / campo obrigatório ausente / validação (zod)
401Não autenticado (token ausente/inválido)
403Sem permissão (perfil insuficiente)
404Recurso não encontrado
409Conflito (unicidade / transição de status inválida)
422Regra de negócio / referência (FK) inexistente
500Erro interno
503Serviço indisponível (dashboard)

Execução local

npm install
cp .env.example .env
npm run migrate
npm run seed
npm run dev

Configure DATABASE_URL antes de rodar migrations, seed ou servidor. A API sobe em http://localhost:3000, salvo quando PORT definir outra porta.

Exemplos de teste manual

As rotas podem ser testadas no Thunder Client, Postman, Insomnia ou por curl. A seção 3.7 do WAD concentra a tabela detalhada de endpoints e os exemplos principais.

Login

curl -X POST http://localhost:3000/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@safracontrol.com","senha":"123456"}'

Listar parceiros

curl -X GET http://localhost:3000/api/parceiros

Criar parceiro

curl -X POST http://localhost:3000/api/parceiros \
  -H "Content-Type: application/json" \
  -d '{
    "nome": "Fornecedor Teste",
    "tipo_pessoa": "juridica",
    "cpf_cnpj": "12345678000199",
    "criado_por": "00000000-0000-0000-0000-000000000001",
    "email": "fornecedor.teste@example.com"
  }'

Enviar para validação

curl -X PUT http://localhost:3000/api/parceiros/ID_DO_PARCEIRO/validacao \
  -H "Content-Type: application/json" \
  -d '{
    "atualizado_por": "00000000-0000-0000-0000-000000000001",
    "comentario": "Cadastro pronto para validacao."
  }'

Registrar interação

curl -X POST http://localhost:3000/parceiros/ID_DO_PARCEIRO/interacoes \
  -H "Content-Type: application/json" \
  -d '{
    "registrado_por": "00000000-0000-0000-0000-000000000001",
    "tipo": "visita",
    "descricao": "Visita tecnica registrada para acompanhamento do parceiro.",
    "data": "2026-06-02"
  }'
Safra Control — documentação da WebAPI (WAD seção 3.7). Gerada a partir das rotas, controllers e schemas (zod) do backend. Padrão de erro: { "error": "…" } (Dashboard e Exportação usam { "erro": "…" }).
